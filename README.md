# GlassTube

基于 Canny 边缘、亚像素拼接与保守几何约束的玻璃管最大可插入直棒通径分析工具。

本项目面向玻璃管的二维侧视测量场景：在硬件保证弯曲主要位于相机像面内的前提下，利用端面孔径与全长侧壁约束，估计能够沿整根玻璃管通过的最大**直**棒直径。

> 本仓库的文档不包含原始图像、样本标识、采集批次、设备路径、标定数值、真实测量结果、访问凭据或任何密钥信息。运行时请通过本地配置提供授权可用的输入图像。

## 方法概览

完整流程如下：

```text
独立左右端面图校验
  → 端面圆环粗定位与 Canny 轮廓追踪
  → 保守端面孔径估计
  → 侧视图序列亚像素配准与拼接
  → 上下内壁窄带 Canny 检测
  → 动态规划连续路径跟踪与亚像素细化
  → 局部缩颈与测量不确定度折减
  → 连续斜率优化最大可通过直棒
```

算法以“避免假通过”为优先目标：端面、侧壁缺口、局部缩颈、拼接缝和定位不确定度都会形成约束或安全折减，而不会被用于放大可通过直径。

## 核心脚本

| 脚本 | 作用 |
|---|---|
| `pj4.m` | 快捷启动脚本：读取默认配置并执行完整分析。 |
| `glass_tube_default_config.m` | 集中定义输入、标定、拼接、端面、侧壁、优化、验证和输出参数。 |
| `run_glass_tube_analysis.m` | 主流水线入口：依次执行端面分析、侧视拼接、内壁检测、直棒求解与结果保存。 |
| `calibrate_standard_block_scale.m` | 基于标准件边缘计算侧视相机和端面相机的像素标定比例。 |
| `analyze_endface_canny.m` | 对单张端面图进行圆环定位、全分辨率 Canny 轮廓追踪、鲁棒圆拟合和保守孔径计算。 |
| `stitch_tube_strip.m` | 对侧视图序列进行自然排序、亚像素配准、累计垂直漂移校正和预分配拼接。 |
| `detect_side_inner_walls.m` | 用极性正确的 Canny 候选和带状动态规划跟踪上下内壁，并给出缩颈与不确定度。 |
| `solve_max_rod_diameter.m` | 在端面孔径、侧壁形状、局部缩颈和不确定度约束下，优化最大直棒直径与轴线。 |
| `save_glass_tube_diagnostic.m` | 导出叠加内壁轨迹、直棒包络、接触点和质量摘要的诊断图。 |
| `review_side_robustness.m` | 面向多组侧视序列的离线鲁棒性审查与汇总。 |
| `diagnose_failed_side_groups.m` | 对异常侧视图组导出拼接与梯度诊断信息，辅助定位失败原因。 |
| `tests/GlassTubeCoreTest.m` | 基于合成数据的核心单元测试，覆盖内壁跟踪和通径优化的关键保守性规则。 |

## 快速开始

### 1. 准备输入与配置

在 `glass_tube_default_config.m` 中配置本地可用的：

- 一组侧视序列图像；
- 两张**相互独立**的左、右端面图像；
- 与当前成像系统匹配的标定和 ROI 参数。

左右端面图不能使用同一路径，也不能使用内容相同的副本。主流程会对输入做一致性检查，以避免将单端信息误用为双端约束。

### 2. 更新标定（图像系统变化时）

当相机、镜头、倍率或标准件图像发生变化时，运行：

```matlab
calibration = calibrate_standard_block_scale();
```

该步骤会生成供默认配置加载的标定结果。请使用经过确认的标准件和本地质量规范验证标定是否有效。

### 3. 执行分析

快捷方式：

```matlab
pj4
```

或以函数方式运行：

```matlab
cfg = glass_tube_default_config();
result = run_glass_tube_analysis(cfg);
```

`result` 会包含最大保守直棒直径、最优直棒轴线、端面分析结果、侧壁轨迹、拼接质量指标、处理耗时和认证状态等信息。

## 保守性与质量门控

项目使用以下规则控制误判风险：

- **端面孔径采用保守估计**：基于内轮廓低分位半径并扣除安全余量，不直接把平均拟合圆作为最终通径。
- **侧视约束只能减小通径**：局部缩颈和测量不确定度只会压缩有效半径，不能放大端面给出的孔径。
- **直接观测与插值明确区分**：`observed` 表示上下内壁均有直接 Canny 支持；短缺口可标为 `interpolated`，但不会伪装成直接观测。
- **长缺口失败关闭**：超出允许范围的无支持区段会导致流程拒绝输出可认证的通径，而不是依赖未经验证的插值。
- **拼接质量受控**：相邻图像的相关峰和峰旁比必须满足门限；是否允许名义位移降级由配置明确控制。
- **直棒按法向宽度计算**：对于倾斜轴线，优化目标使用相对杆轴的实际法向宽度，避免由垂直间隙造成高估。
- **认证状态独立记录**：只有输入独立性和关键质量门限均满足时，结果才可被标记为可认证；具体验收仍应结合实物通止规或独立验证流程完成。

## 输出

主流程可根据配置生成以下类型的产物：

- 包含完整计算中间量和最终结论的 MATLAB 结果结构；
- 端面分析缓存，以便在输入和参数未变化时避免重复计算；
- 内壁轨迹的可选表格导出；
- 可视化诊断图，展示内壁轨迹、保守腔体、最优直棒、接触点和质量摘要；
- 侧视图组的离线鲁棒性审查汇总。

输出位置、是否写入图像或表格、缓存策略等均由配置控制。建议将原始图像、结果产物和本地配置按组织的数据管理与访问控制要求保存，不要提交到公开仓库。

## 测试

运行核心回归测试：

```matlab
results = runtests(fullfile('tests', 'GlassTubeCoreTest.m'));
assertSuccess(results);
```

测试使用合成场景，覆盖：

- 上下内壁路径定位精度；
- 短遮挡下的观测与插值语义；
- 垂直镜像对称性；
- 初始化先验失效时的回退行为；
- 平直、倾斜和弯曲通道中的直棒优化；
- 局部缩颈不被平滑扩大；
- 连续优化与独立密集搜索的一致性；
- 倾斜直棒的物理法向宽度修正。
